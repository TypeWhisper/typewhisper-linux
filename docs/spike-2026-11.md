# Platform spike, November 2026

Before any app code, a spike checked the Linux desktop features TypeWhisper depends on. Date: 2026-11-25. Everything below ran on Apple Silicon in headless VMs, so x86_64 and GPU inference were not covered.

## Environment

- Lima 2.3.0, two headless VMs (vz, 6 CPUs, 8 GiB, 60 GiB) from the Fedora 45 Cloud aarch64 image. Each mounts only the working folder.
  - `tw-gnome`: GNOME 51.1, xdg-desktop-portal 1.22.1, xdg-desktop-portal-gnome 51.0, GTK 4.24.1, libadwaita 1.10.0, PipeWire 1.6.11, Rust 1.100.0, Flatpak 1.18.4. Start: `tools/vm/start-gnome-session-headless.sh` (drop-in for `org.gnome.Shell@.service` with `--headless --virtual-monitor 1280x800`, then `gnome-session`). Without gnome-session the settings daemons are missing and global shortcuts never fire.
  - `tw-kde`: Plasma 6.8.3 (plasma-workspace, xdg-desktop-portal-kde, kglobalacceld, layer-shell-qt). Start: `tools/vm/start-plasma-headless.sh` (drop-in for `plasma-kwin_wayland.service` with `--virtual`, then `plasma-workspace-wayland.target`). The Wayland socket is `wayland-1`.
- Test drivers:
  - AT-SPI (`tools/desktop-probes/atspi_tool.py`, `tools/desktop-probes/atspi_press.py`) presses dialog buttons and reads widgets. Qt needs `QT_LINUX_ACCESSIBILITY_ALWAYS_ON=1` and `org.a11y.Status.IsEnabled=true`.
  - On GNOME, Mutter's private remote desktop API (`tools/desktop-probes/mutter_keys.py`) simulates keys. On KDE the RemoteDesktop portal does it (`tools/desktop-probes/portal_keys.py`).
  - The GNOME session starts in the Activities overview, which `OverviewActive=false` over D-Bus closes. Screenshots come from the Screenshot portal (`tools/desktop-probes/screenshot.py`).

## 1. Rust + libadwaita app, Flatpak: passed

- The app crate (gtk4-rs 0.11, libadwaita-rs 0.9) builds in 20 s in the VM and runs in GNOME 51.
- A Flatpak manifest like `packaging/flatpak/com.typewhisper.TypeWhisper.json` builds the same app as a Flatpak on `org.gnome.Platform//51` with `org.freedesktop.Sdk.Extension.rust-stable//26.08` and installs it. In a VM, `flatpak-builder` needs `--disable-rofiles-fuse`. The spike lets cargo use the network during the build; Flathub needs vendored crates instead.

## 2. Global shortcut: passed on GNOME and KDE

`tools/desktop-probes/global_shortcuts.py`

| | GNOME 51 | Plasma 6.8.3 |
| --- | --- | --- |
| Consent | "Add Keyboard Shortcuts" dialog, once | "Global Shortcuts Requested" dialog, once |
| `preferred_trigger` | accepts `<Control><Alt>d` and the XDG format | needs the XDG shortcuts format, `CTRL+ALT+d` (keysym case matters). `<Control><Alt>d` registers the shortcut **without a key** and later binds keep the empty key |
| Hold (1.5 s) | `Activated` on press, `Deactivated` on release | same |
| While held | auto-repeat sends another `Activated` about every 33 ms after 0.5 s | no repeats |
| Timestamps | real values | always 0 |
| Stored in | `org.gnome.settings-daemon.global-shortcuts` | kglobalaccel (`kglobalshortcutsrc`) |

Consequences: always send `preferred_trigger` in the XDG format. Treat repeated `Activated` without a `Deactivated` as one press, and do not rely on timestamps. Hold-to-talk works on both desktops. Shortcuts do not fire on GNOME while the Activities overview is open.

## 3. Text insertion: passed with paste on GNOME and KDE

`tools/desktop-probes/insert_text.py`, target `tools/desktop-probes/target_app.py` (GTK 4 text view that logs its content)

- **Method that works**: a RemoteDesktop session (keyboard) with `Clipboard.RequestClipboard` before `Start`, then `Clipboard.SetSelection`, answering every `SelectionTransfer` with `SelectionWrite`, then Ctrl+V through `NotifyKeyboardKeysym`. "Grüße aus TypeWhisper: äöü ß € 😀 中文" arrives completely on GNOME and on KDE. The app must keep its main loop running while it sends the keys, about 50 ms apart; without that nothing was pasted on GNOME.
- **Keysym typing fails** for every character the active layout lacks (ä, ö, ü, ß, €, emoji, CJK on the US layout). It is no option for dictated text.
- **Consent**:
  - GNOME: dialog with "Allow Remote Interaction" **off** by default, while "Allow Clipboard Access" and "Remember This Selection" are on. Onboarding must tell the user to switch on remote interaction.
  - KDE: "Allow … to gain remote control privileges? Move the pointer and type keystrokes", with "without asking next time" on by default.
- **Restore token** (`persist_mode` 2): the next `Start` is granted after 0.0 s without a dialog on both desktops. Every `Start` returns a new token, which must replace the stored one.
- **GNOME shows an orange remote-control indicator** in the top bar while a RemoteDesktop session is open. TypeWhisper must open the session only for the insertion and close it right after. With the restore token that adds no visible delay.
- The compositor asks for the clipboard data right away and again when the target pastes, so the app answers transfers until it closes the session.
- Open: pasting overwrites the user's clipboard. Restoring it needs `SelectionRead` and `SelectionOwnerChanged`. Terminals (Ctrl+Shift+V), Firefox, LibreOffice and Qt apps are still to be tested.

## 5. Overlay and frontmost app on GNOME: passed (prototype)

`gnome-shell-extension/typewhisper@typewhisper.com`, app stand-in `tools/desktop-probes/fake_app_shell_bridge.py`

- The extension draws the indicator as top chrome above all windows from the app's `StateChanged(u version, s state, s text)` signal. It showed "● Listening… 0:03" at the bottom centre. States change and hide without delay.
- It reports `FocusChanged(u version, s app_id, s title)` to the owner of `com.typewhisper.TypeWhisper`, only while that name has an owner. It accepts signals only from that owner. A window without a `.desktop` file reports a placeholder ID such as `window:1`.
- On Wayland a newly installed extension loads only after a new session (log out and in). Installation needs `disable-user-extensions=false` and the UUID in `enabled-extensions`.
## 5. Overlay on KDE: passed

`tools/desktop-probes/layer_overlay.py` with gtk4-layer-shell 1.3.0

- A GTK 4 window becomes a layer surface (layer `OVERLAY`, anchored to the bottom, keyboard mode `NONE`). KWin reports support.
- While the overlay is shown, text typed through the portal still reaches the focused target window, so the overlay takes no focus.
- gtk4-layer-shell has to load before libwayland. From Python that needs `LD_PRELOAD=/usr/lib64/libgtk4-layer-shell.so.0`; a Rust app links it first instead.
- No screenshot: the Screenshot portal fails in the headless KWin session (response 2), even after "Allow".

## 4. Microphone through the Pulse API in Flatpak: passed

`tw_platform::audio::record` (libpulse-simple, 16 kHz mono f32), example `record`

- A virtual microphone (`pactl load-module module-pipe-source`, default source) fed with a 440 Hz sine at amplitude 0.5.
- Native and from the Flatpak (`--socket=pulseaudio`), 3 s each: 48,000 samples, RMS 0.3535 (exactly 0.5/√2), estimated frequency 440 Hz. No sample is lost and the level is unchanged.
- The Flatpak shows no permission dialog for the microphone.

## 6. Plugin as its own process: passed

`plugins/parakeet` (Rust, `sherpa-onnx` crate 2.0.3, static), host `tools/desktop-probes/plugin_host.py`

- Wire format on stdin/stdout: u32 big-endian length, one kind byte (1 = JSON-RPC 2.0, 2 = PCM f32le 16 kHz mono), payload. Methods: `initialize` (protocol version check), `transcription.loadModel`, `transcription.begin`, PCM frames of 100 ms, `transcription.end`, `shutdown`.
- The release binary is 34 MB and needs only libc, libm, libstdc++ and libgcc_s, so the same file runs on the host and inside a Flatpak runtime. The ZIP with `manifest.json` and `bin/` is 12 MB.
- The host checks the package paths, installs to `~/.local/share/typewhisper/plugins/com.typewhisper.parakeet` and starts the process.
- Parakeet TDT 0.6B v3 int8 (sherpa-onnx export, 487 MB download) on the VM's aarch64 CPU with 4 threads: model load 981 ms; a 4.2 s German dictation sample decoded in 128 ms, 132 ms round trip including the audio frames. Result: "Wir erstellen eine konstante retryCount mit dem Wert 3." (reference: "Erstelle eine Konstante retry count mit dem Wert drei").

## 7. Shared formats: passed

`crates/tw-formats` (serde, `caseless`, `unicode-normalization`), `cargo test`

- The five Mac operation fixtures (dictionary v1, CTC v1, regex v1 and v2, legacy snippet) parse and serialize back to identical JSON, including unknown fields.
- The regex identity fixture matches exactly (pattern bytes, no Unicode normalization).
- 29 identity vectors generated on the Mac with Foundation's own folding (`crates/tw-formats/tools/gen_vectors.swift`) match: ß→ss, ﬁ→fi, ﬀ→ff, Kelvin sign→k, Ångström sign→a, İ→i, dotless ı stays, final sigma→σ, ŉ→ʼn, fullwidth letters stay, NBSP is trimmed, emoji stay. The Rust rule: trim, NFD, full Unicode case folding, drop combining marks, NFC.
- Legacy item IDs without base64 (`dictionary:correction:recieve`, `snippet:;hello`) still occur in Mac data and have to be accepted when reading.
